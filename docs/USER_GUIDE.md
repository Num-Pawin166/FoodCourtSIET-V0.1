## ส่วนที่ 1 – นักศึกษา / บุคลากร

### 1.1 ติดตั้งแอป
**Android**
1. ดาวน์โหลดไฟล์ `FoodCourt-SIET-student.apk` (รับจากผู้ดูแลระบบ)
2. เปิดไฟล์แล้วกด **ติดตั้ง** ถ้ามือถือถามเรื่อง "ติดตั้งแอปจากแหล่งที่ไม่รู้จัก" ให้กด **อนุญาต**
3. ถ้าเคยติดตั้งเวอร์ชันเก่าไว้ ติดตั้งทับได้เลย ข้อมูลไม่หาย

**iPhone / ใช้ผ่านเบราว์เซอร์**
1. เปิด Safari ไปที่ **https://foodcourt-siet.onrender.com/app/**
2. กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรชี้ขึ้น) → **เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)**
3. จะได้ไอคอน FoodCourt บนหน้าจอ ใช้งานเหมือนแอป

> 💡 ถ้าเปิดแอปครั้งแรกของวันแล้วโหลดนาน (ไม่เกินประมาณ 1 นาที) เป็นเพราะเซิร์ฟเวอร์กำลังเริ่มทำงาน รอสักครู่ได้เลย

### 1.2 เข้าสู่ระบบ
- กด **เข้าสู่ระบบด้วย Google** แล้วเลือกบัญชี **@kmitl.ac.th** (บัญชี Gmail ทั่วไปใช้ไม่ได้)
- ล็อกอินครั้งแรกระบบจะสร้างบัญชีให้อัตโนมัติ ชื่อผู้ใช้คือรหัสนักศึกษาจากอีเมล
- ถ้ามีบัญชีแบบรหัสผ่าน ให้กรอกชื่อผู้ใช้และรหัสผ่านแล้วกด **Login**

### 1.3 เลือกร้านและเมนู
1. หน้า **Home** แสดงร้านทั้งหมด พร้อมสถานะ **เปิดอยู่ / ปิดแล้ว** เวลารอ และจำนวนคิว
2. หาร้านได้ 2 แบบ:
   - **ค้นหา:** พิมพ์ชื่อร้านหรือชื่อเมนู เช่น "กะเพรา"
   - **กรองตามหมวด:** แตะปุ่มหมวดด้านบน เช่น อาหารจานเดียว / เส้น / เครื่องดื่ม
3. แตะร้านเพื่อดูเมนู แล้วกด **＋ / −** เพื่อเลือกจำนวน
4. กด ♥ ที่รูปเมนูเพื่อเก็บไว้ใน **เมนูโปรด**
5. กดแถบสีชมพู **เพิ่มลงตะกร้า** ด้านล่าง

> สั่งได้ทีละร้านต่อหนึ่งออเดอร์ ถ้าเลือกเมนูจากร้านอื่น แอปจะถามก่อนว่าจะล้างตะกร้าเดิมไหม

### 1.4 ให้ AI ช่วยเลือกเมนู
1. หน้า Home → กดการ์ดสีดำ **ถาม AI ช่วยเลือกเมนู**
2. พิมพ์สิ่งที่ต้องการ เช่น
   - "งบ 50 บาท ไม่เผ็ด รับได้ภายใน 12:00"
   - "อยากกินเส้น ร้านที่คิวน้อย"
   - "ไม่กินหมู"
3. AI จะแนะนำเมนูจากร้านที่เปิดอยู่จริง แตะการ์ดเมนูเพื่อไปที่ร้านนั้น

### 1.5 ยืนยันคำสั่งซื้อ
1. ในหน้า **ตะกร้าของฉัน** แก้จำนวนได้ด้วย ＋ / −
2. **เลือกเวลารับอาหาร** แอปแสดงเฉพาะช่วงเวลาที่ร้านทำทัน
3. **หมายเหตุถึงร้าน** (ถ้ามี) เช่น "ไม่ใส่ผัก" หรือ "แยกน้ำซุป"
4. **เลือกวิธีชำระเงิน**
   - **โอนพร้อมเพย์:** สแกน QR แล้วแนบสลิป (ใช้ได้เฉพาะร้านที่เปิดรับโอน)
   - **จ่ายที่ร้าน:** จ่ายตอนรับอาหาร
5. กด **ยืนยันคำสั่งซื้อ**

### 1.6 ชำระเงินด้วยพร้อมเพย์
1. หลังยืนยันคำสั่งซื้อ แอปจะเปิดหน้า **ชำระเงิน** ที่มี QR และยอดเงินให้
2. เปิดแอปธนาคาร → **สแกน QR** (ยอดเงินใส่ไว้ให้แล้ว) → ตรวจชื่อร้าน → โอน
3. บันทึกภาพสลิป
4. กลับมาที่แอป FoodCourt → กด **แนบสลิป** → เลือกรูปสลิป
5. สถานะจะเปลี่ยนเป็น **"รอร้านตรวจสลิป"** แล้วเปลี่ยนเป็น **"ชำระเงินแล้ว"** เมื่อร้านยืนยัน

ถ้าร้านแจ้งว่า **สลิปไม่ผ่าน** จะเห็นเหตุผลบนการ์ดออเดอร์ ให้กด **ชำระเงิน** แล้วแนบสลิปใหม่
ถ้าออกจากหน้าชำระเงินไปก่อน กลับมาจ่ายทีหลังได้ที่ **Orders → ปุ่ม "ชำระเงิน"** บนการ์ดออเดอร์

### 1.7 ติดตามออเดอร์และรับอาหาร
1. แท็บ **Orders → กำลังดำเนินการ**
2. ดู **หมายเลขคิว** (เช่น A-027) และจำนวน**คิวก่อนหน้า**
3. ไทม์ไลน์สถานะอัปเดตเองทุก 5 วินาที: ร้านรับออเดอร์ → กำลังทำอาหาร → **พร้อมรับอาหาร**
4. เมื่อการ์ดเป็นสีเขียว "อาหารพร้อมแล้ว!" ให้ไปที่ร้านแล้ว**แสดงหมายเลขคิว**

**ยกเลิกออเดอร์:** ทำได้เฉพาะตอนที่ร้านยังไม่กดรับ โดยกด **ยกเลิกออเดอร์** ใต้ไทม์ไลน์

### 1.8 ประวัติและบัญชี
- **Orders → ประวัติ:** ดูออเดอร์ที่จบแล้ว กด **สั่งอีกครั้ง** เพื่อใส่เมนูเดิมลงตะกร้า
- **User:** จำนวนออเดอร์และยอดใช้จ่ายเดือนนี้ เมนูโปรด และปุ่มออกจากระบบ

## ส่วนที่ 2 – ร้านค้า

### 2.1 ติดตั้งและเข้าสู่ระบบ
1. ติดตั้งไฟล์ `FoodCourt-SIET-vendor.apk` (ไอคอนพื้นสีเข้ม ชื่อ "FoodCourt ร้านค้า")
2. กรอก**ชื่อผู้ใช้ร้าน**และ**รหัสผ่าน**ที่ได้รับจากผู้ดูแลศูนย์อาหาร
3. ใช้ผ่านคอมพิวเตอร์ได้เช่นกัน ที่ **https://foodcourt-siet.onrender.com**

> ⚠️ **เปิดแอปค้างไว้ระหว่างเวลาขาย** และ**เปิดเสียงมือถือ** (เสียงสื่อ/media) ไว้ ไม่งั้นจะไม่ได้ยินเสียงเตือนออเดอร์ใหม่

### 2.2 รับออเดอร์
เมื่อมีออเดอร์ใหม่:
- 🔔 **เสียงดังและมือถือสั่นซ้ำทุก 3 วินาที**
- 🟥 มี**แถบแดงด้านบน**ทุกหน้า "มีออเดอร์ใหม่ X รายการ รอร้านกดรับ"
- **เสียงจะดังจนกว่าจะกดรับหรือปฏิเสธออเดอร์ใหม่ครบทุกใบ**

ขั้นตอนทำออเดอร์ (แท็บ **ออเดอร์**):

| สถานะ | ปุ่มที่กด | ความหมาย |
|---|---|---|
| ออเดอร์ใหม่ | **รับออเดอร์** / ปฏิเสธ | ยืนยันว่าร้านรับทำ (ถ้าปฏิเสธต้องใส่เหตุผล เช่น "วัตถุดิบหมด") |
| รับแล้ว | **เริ่มทำ** / ยกเลิก | เริ่มทำอาหาร |
| กำลังทำ | **ทำเสร็จแล้ว** | ลูกค้าจะเห็นว่า "พร้อมรับอาหาร" |
| พร้อมรับ | **ลูกค้ารับแล้ว** | ปิดออเดอร์ |

บนการ์ดออเดอร์มี**หมายเลขคิว**ตัวใหญ่ **เวลาที่ลูกค้าจะมารับ** รายการอาหาร และ**หมายเหตุ** (แถบสีเหลือง)

### 2.3 ตรวจการชำระเงิน
แถบสถานะการจ่ายเงินบนการ์ดออเดอร์:

| แถบ | ความหมาย | สิ่งที่ต้องทำ |
|---|---|---|
| 💵 จ่ายที่ร้าน | ลูกค้าจะจ่ายเงินสดตอนรับ | รับเงินแล้วแตะแถบ → **รับเงินสดแล้ว** (เพื่อบันทึก ไม่บังคับ) |
| 📱 รอลูกค้าโอน | ลูกค้ายังไม่แนบสลิป | รอ |
| 🟨 สลิปรอตรวจ | ลูกค้าแนบสลิปแล้ว | **แตะแถบเพื่อดูสลิป** |
| ✅ ชำระเงินแล้ว | ยืนยันแล้ว | — |

**ตรวจสลิป:**
1. แตะแถบ "สลิปรอตรวจ" → ดูรูปสลิป
2. เช็ค **ยอดเงิน**, **ชื่อผู้รับ (ร้านเรา)** และ **วันเวลา** และควรเช็คว่าเงินเข้าบัญชีจริงในแอปธนาคารของร้าน
3. ถูกต้อง → กด **ยืนยันรับเงิน**
4. ไม่ถูกต้อง → กด **สลิปไม่ถูกต้อง** แล้วใส่เหตุผล เช่น "ยอดเงินไม่ตรง" ลูกค้าจะเห็นเหตุผลและแนบสลิปใหม่ได้

### 2.4 จัดการเมนู (แท็บ **เมนู**)
- **เพิ่มเมนู:** กดปุ่ม **＋ เพิ่มเมนู** แล้วกรอกชื่อ รายละเอียด ราคา
- **ใส่รูปเมนู:** แตะช่อง **เพิ่มรูปเมนู** → **ถ่ายรูป** หรือ **เลือกจากคลังภาพ** แล้วกด **บันทึก**
- **แก้ไข / เปลี่ยนรูป / ลบรูป:** แตะที่เมนู → แตะรูปเพื่อเปลี่ยนหรือลบ
- **ลบเมนู:** แตะเมนู → ไอคอนถังขยะ 🗑
- **ของหมด:** ปิด**สวิตช์**ท้ายเมนู ลูกค้าจะสั่งเมนูนั้นไม่ได้จนกว่าจะเปิดสวิตช์คืน

### 2.5 ข้อมูลร้านและโปรไฟล์ (แท็บ **ร้านของฉัน**)
| รายการ | วิธีใช้ |
|---|---|
| รูปร้าน | แตะรูปด้านบน → ถ่ายรูป / เลือกจากคลังภาพ / ลบรูป (รูปจะแสดงในหน้าแรกของแอปนักศึกษา) |
| ชื่อเจ้าของร้าน | แตะชื่อ → แก้ไข → บันทึก |
| เปลี่ยนรหัสผ่าน | ใส่รหัสเดิม และรหัสใหม่ 2 ครั้ง (อย่างน้อย 4 ตัวอักษร) |
| เปิดรับออเดอร์ | ปิดสวิตช์เมื่อต้องการหยุดรับออเดอร์ชั่วคราว (ปิดได้จากหน้าออเดอร์ด้วย) |
| เวลาเปิด–ปิด / เวลารอ | ใช้คำนวณช่วงเวลารับอาหารที่ลูกค้าเลือกได้ |
| รับโอนพร้อมเพย์ | ใส่**เบอร์มือถือหรือเลขบัตรประชาชนที่ผูกพร้อมเพย์ของร้าน** ถ้าเว้นว่าง ลูกค้าจะจ่ายที่ร้านได้อย่างเดียว |

กด **บันทึก** หลังแก้ข้อมูลร้าน
ชื่อร้าน หมวดหมู่ และรหัสคิว แก้ได้โดยผู้ดูแลศูนย์อาหารเท่านั้น

> 💡 หลังใส่เลขพร้อมเพย์ ควรลองสั่งอาหารเองแล้วสแกน QR ด้วยแอปธนาคาร ดูว่า**ชื่อผู้รับเป็นชื่อร้านเรา**ก่อนเปิดให้ลูกค้าใช้ ถึงตอนกดโอนก็ยกเลิกได้เลย ไม่ต้องโอนจริง

## ส่วนที่ 3 – ผู้ดูแลศูนย์อาหาร

เข้าใช้งานผ่านคอมพิวเตอร์ที่ **https://foodcourt-siet.onrender.com** ด้วยบัญชีผู้ดูแล

### 3.1 ภาพรวม
- ออเดอร์และยอดขายวันนี้ ยอดขาย 14 วัน และจำนวนร้านที่เปิดอยู่
- **กราฟยอดขายรายวัน** (เอาเมาส์ชี้แท่งกราฟเพื่อดูตัวเลข)
- ยอดขายแยกตามร้าน และเมนูขายดี 5 อันดับ

### 3.2 เพิ่มร้านใหม่ (2 ขั้นตอน)
1. เมนู **ร้านค้า → ＋ เพิ่มร้าน** แล้วกรอก:
   - **รหัสคิว:** ตัวอักษรอังกฤษ 1–2 ตัว ห้ามซ้ำกับร้านอื่น ใช้เป็นตัวนำหน้าเลขคิว เช่น F → F-001
   - **ชื่อร้าน / หมวดหมู่ / เวลาทำการ / เวลารอ**
2. เมนู **ผู้ใช้งาน → ＋ เพิ่มผู้ใช้**
   - บทบาท = **ร้านค้า** แล้วเลือกร้านที่เพิ่งสร้าง
   - ตั้งชื่อผู้ใช้และรหัสผ่านชั่วคราว แล้วแจ้งร้าน (ร้านเปลี่ยนรหัสผ่านเองในแอปได้)

### 3.3 จัดการผู้ใช้
- **ค้นหา:** ด้วยชื่อ รหัสนักศึกษา หรืออีเมล และกรองตามบทบาทได้
- **ลืมรหัสผ่าน:** **แก้ไข** → ใส่รหัสผ่านใหม่ → บันทึก
- **ระงับบัญชี:** **แก้ไข** → ปิดสวิตช์ **เปิดใช้งานบัญชี**
- นักศึกษาที่ล็อกอินด้วย Google ระบบสร้างบัญชีให้เอง ไม่ต้องสร้างให้

### 3.4 ดูออเดอร์ทั้งหมด
เมนู **ออเดอร์ทั้งหมด** กรองได้ตามร้าน สถานะ และวันที่ และดูสถานะการชำระเงินของแต่ละออเดอร์ได้

### 3.5 สิ่งที่ต้องทำก่อนเปิดใช้งานจริง
- [ ] เปลี่ยนรหัสผ่าน `admin` และบัญชีร้านตัวอย่างทั้งหมด
- [ ] ลบหรือแก้ร้านและเมนูตัวอย่างให้เป็นข้อมูลจริง
- [ ] ให้ทุกร้านใส่หมายเลขพร้อมเพย์ของตัวเอง และลองสแกนทดสอบ
